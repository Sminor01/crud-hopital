# Инфологическая модель базы данных
## Информационная система учета сотрудников факультета

### Описание предметной области
Система предназначена для управления и учета персонала факультета университета. Позволяет хранить информацию о сотрудниках, их должностях, трудовых договорах и историю трудоустройства.

## Сущности и их атрибуты

### 1. СУЩНОСТЬ: Departaments (Факультеты)
Описывает структурные подразделения университета

**Атрибуты:**
- `departament_id` - уникальный идентификатор факультета (ключ)
- `departament_name` - наименование факультета
- `building_address` - адрес корпуса
- `phone` - контактный телефон
- `email` - электронная почта

### 2. СУЩНОСТЬ: Positions (Должности)
Справочник должностей сотрудников

**Атрибуты:**
- `position_id` - уникальный идентификатор должности (ключ)
- `position_name` - наименование должности
- `salary_range` - диапазон заработной платы
- `responsibilities` - должностные обязанности

### 3. СУЩНОСТЬ: Employees (Сотрудники)
Персональная информация о сотрудниках

**Атрибуты:**
- `employee_id` - уникальный идентификатор сотрудника (ключ)
- `last_name` - фамилия
- `first_name` - имя
- `middle_name` - отчество
- `birth_date` - дата рождения
- `phone` - контактный телефон
- `email` - электронная почта
- `education` - уровень образования

### 4. СУЩНОСТЬ: Contracts (Трудовые договоры)
Договоры с сотрудниками

**Атрибуты:**
- `contract_id` - уникальный идентификатор договора (ключ)
- `contract_number` - номер договора
- `start_date` - дата начала действия
- `end_date` - дата окончания действия
- `contract_type` - тип договора (основной, по совместительству, временный)
- `employee_id` - внешний ключ на сотрудника
- `departament_id` - внешний ключ на факультет
- `position_id` - внешний ключ на должность

### 5. СУЩНОСТЬ: EmploymentHistory (История трудоустройства)
История трудовой деятельности сотрудников

**Атрибуты:**
- `history_id` - уникальный идентификатор записи (ключ)
- `employee_id` - внешний ключ на сотрудника
- `departament_id` - внешний ключ на факультет
- `position_id` - внешний ключ на должность
- `start_date` - дата начала работы
- `end_date` - дата окончания работы
- `status` - статус работы (работает, уволен, в отпуске)

## Связи между сущностями

### Связь 1: Employees ↔ Contracts (Один ко многим)
Один сотрудник может иметь несколько трудовых договоров (исторических и текущих)
- Связь обязательная с обеих сторон
- При удалении сотрудника удаляются все его договоры

### Связь 2: Departments ↔ Contracts (Один ко многим)
Один факультет может содержать множество договоров с сотрудниками
- Связь обязательная с обеих сторон
- При удалении факультета связанные договоры помечаются как архивные

### Связь 3: Positions ↔ Contracts (Один ко многим)
Одна должность может быть присвоена многим сотрудникам
- Связь обязательная с обеих сторон
- При удалении должности не удаляются договоры (историческая справка)

### Связь 4: Employees ↔ EmploymentHistory (Один ко многим)
Один сотрудник имеет множество записей в истории трудоустройства
- Связь обязательная с обеих сторон
- При удалении сотрудника удаляется его история

### Связь 5: Departments ↔ EmploymentHistory (Один ко многим)
Один факультет связан с множеством записей в истории трудоустройства
- Связь обязательная с обеих сторон

### Связь 6: Positions ↔ EmploymentHistory (Один ко многим)
Одна должность связана с множеством записей в истории трудоустройства
- Связь обязательная с обеих сторон

## Требуемые отчеты

### Отчет 1: Список сотрудников по факультетам
Выводит всех сотрудников, сгруппированных по факультетам с указанием текущей должности и статуса договора.

### Отчет 2: Статистика по должностям
Показывает количество сотрудников по каждой должности, среднюю зарплату и количество активных договоров.

### Отчет 3: История трудоустройства сотрудника
Отображает полную историю работы сотрудника: даты, факультеты, должности, статусы.

### Отчет 4: Действующие договоры на факультете
Выводит список всех активных (не истекших) договоров по выбранному факультету с информацией о сотрудниках и должностях.
